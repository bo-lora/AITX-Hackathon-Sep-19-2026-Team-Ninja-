## If a carrier disappears
(Read from the live admin screens on https://demo.openemr.io/openemr as admin/pass on 2026-09-19 ~11:50 CDT. Nothing was saved.)
1. Top menu: Admin > Practice > Practice Settings
2. On the Practice Settings page, click the tab/link "Insurance Companies"
3. Click "Add a Company"
4. Fill the form. Labels shown on screen, in order: Deactivate, Name, Attn, Address, Address, City, State, Zip Code, Phone, Fax, Payer ID, Payer Type, Default X12 Partner, CQM Source of Payment
   Example: Name = HACKDEMO Lone Star Health ; Address = 100 Congress Ave ; City = Austin ; State = TX ; Zip Code = 78701
   (No field carries an HTML "required" attribute; which fields the server actually insists on is UNVERIFIED because nothing was saved.)
5. Click "Save" (the other button is "Cancel")
6. The new company then appears in the patient Insurance "Provider" dropdown as "<Name> (<Address>, <City>, <State>, <Zip>)" -- format inferred from the existing entries; UNVERIFIED for a newly added company.
