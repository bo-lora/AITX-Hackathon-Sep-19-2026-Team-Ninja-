Compiler

Later, not train. Train is Load unpacked in Chrome. This weekend’s run is headed OpenEMR. After a path exists, compile the steps that actually sit in an OpenAPI spec onto REST.

Hosted service: cursor-hackathon-6lgm.onrender.com. Source: packages/compiler. Client skill: packages/compile-app-workflows.

What it is

  1. 01

    A Cursor skill POSTs a screen recording (or workflows JSON) plus an OpenAPI spec to the compiler service. The service writes one SKILL.md per workflow.

  2. 02

    Gemini (extract from video) and OpenAI (map onto the spec) run only on the service. Keys are in that host’s env — never in SKILL.md, never in the Chrome extension, never in the zip.

  3. 03

    If the spec has no call, the emitted skill says so. Attach-fax, check-in, and billing stay on the UI. Do not invent REST paths.

How to run it

  1. 01

    Wake the service: open https://cursor-hackathon-6lgm.onrender.com/health — you want {"status":"ok"}. First hit can take a minute if Render was asleep.

  2. 02

    API docs: that same host, /docs. POST /v1/jobs (multipart: video and/or workflows, plus spec). Poll GET /v1/jobs/{id} until status is done or failed.

  3. 03

    Fast path, no Gemini. From the repo root, with fixtures already in packages/compiler:

python packages/compile-app-workflows/scripts/compile_job.py \
  --base-url https://cursor-hackathon-6lgm.onrender.com \
  --workflows packages/compiler/fixtures/openemr/workflows.json \
  --spec packages/compiler/fixtures/openemr/openapi.yaml \
  --out packages/compiler/.cursor/skills

Video path: pass --video your.mp4 instead of --workflows. Extract can take several minutes. Keep polling. Do not call Gemini or OpenAI from your laptop — the service does that.

In Cursor

  1. 01

    Open this repo. The skill compile-app-workflows lives at packages/compile-app-workflows (copy under .cursor/skills).

  2. 02

    Ask to compile a workflow. Attach an mp4 and an OpenAPI file, or say to use the OpenEMR fixtures.

  3. 03

    The skill POSTs the job. It never reads GEMINI_API_KEY. If COMPILE_API_KEY is set on the server, it sends Authorization: Bearer — that is our gate, not Gemini.

What you get

One folder per workflow under packages/compiler/.cursor/skills. Register-patient has real POST /api/patient calls. Process-billing-and-checkout has no matching operations — that is the point. Do not rewrite the markdown to add APIs the mapper dropped.
